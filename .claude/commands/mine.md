Run the **/mine** extraction. Input from the user (may be empty — then use the most recently parked or mentioned solution idea): **$ARGUMENTS**

**Why this exists:** people always think solution-first. That's not a failure — it's ore. A solution someone reaches for encodes a need they haven't articulated yet. Never just park it; smelt it.

Process:

1. **Name the solution** in one line (confirm you've understood it).
2. **Run the extraction** — four questions, answered as hypotheses marked 🤖 for the PM to keep / kill / reword:
   - **Outcome:** what does the user get if this solution existed?
   - **Desire:** what does that outcome imply they wish were true?
   - **Problem:** what obstacle does it remove?
   - **Cohort:** who feels this most sharply?
3. **Route the findings:** each surviving answer becomes a sticky in its named canvas box (desire/problem → the opportunity box; cohort insight → the cohorts box; feelings → empathy mapping). The **solution mechanics go to the parking lot** (e.g. a "Parked Solutions" frame), flagged for the Ideation Workflow.
4. **Link the two:** the parked sticky notes which canvas insights it spawned, so ideation later starts from the need, not just the mechanics.

Never skip the extraction because the solution "seems obvious" — obvious solutions hide the biggest unexamined assumptions.
