# Case study: Checkatrade — barriers to repeat usage

**Date:** 5 July 2026 · **Team:** Taimur Ahmed (PM) + Claude (AI product team) · **Time-box:** 90 minutes

## The one-liner

A full Opportunity Workflow run against a live, time-boxed product challenge — *what are the barriers to homeowners' repeat usage of Checkatrade, and where would you focus?* — on a real UK trades marketplace I had just used first-hand. First-person walked journey → populated canvas → evidence-backed brief with a RICE'd Now / Next / Later / Parked roadmap. Ninety minutes, end to end.

**The opportunity ("the fade"):** Checkatrade wins the job, then vanishes from the homeowner's memory — twelve months later the customer has forgotten the job, the trade, and Checkatrade's role in it. On a P&L growing ~28% at ~2% margin, retention-led growth is strictly cheaper than bought growth, so the fade *is* the repeat-usage barrier worth attacking first.

## The artifacts

1. **[The Opportunity Brief](opportunity-brief.md)** — the synthesised deliverable: summary → cohort definition → empathy evidence → business case on real filing numbers → HMWs → RICE'd roadmap.
2. **[The populated canvas](opportunity-canvas.md)** — the working surface, with evidence links and assumptions marked as assumptions.
3. **[The walked user journey](user-journey.md)** — the first-person evidence base: screenshots, three real job outcomes, verbatim reactions.
4. **[`research/`](research/)** — two mid-canvas fact-packs from the [Researcher Workflow](../../workflows/researcher/): [revenue model](research/fact-pack-revenue-model.md) and [Companies House filings + company jargon](research/fact-pack-filings-jargon.md). The first **overturned the working assumption** (membership-only → transactional marketplace transition) and rewrote the business case mid-run.

## How it was made (the meta-story)

The first live run of this repo — the one that proved the core loop. Research was dispatched *mid-canvas* without breaking flow (flag → dispatch → continue), and came back with the company's own strategy language and real financials, both of which landed in the final brief. Every estimate is marked inline; guesses are labelled as guesses; the one honest data question that would settle the cohort split is named rather than papered over. The run's friction became this repo's first backlog issues.

## What it shows

Working a cold domain to an evidence-backed, prioritised opportunity in a single time-box: define the cohort in the company's own data terms, size the prize on filed numbers, and exit with ranked HMWs — bias to action over completeness, within the time-box, as the ground rules demand.
