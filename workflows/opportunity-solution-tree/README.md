# Opportunity Solution Tree Workflow 🚧

**Status:** coming soon — placeholder so the idea isn't lost.

**Where it sits:** above individual canvas runs. Every Opportunity Canvas produces an opportunity statement (**[Handle]: [verbose-but-simple statement]**, e.g. "Fair Shot: a non-fluent renter gets the highest likelihood of success"). This workflow is where those statements accumulate into a **tree** (after Teresa Torres): outcome at the root, opportunities as branches, solutions and experiments as leaves — so prioritisation happens across opportunities, not just within one canvas.

**What it will produce:** a living opportunity solution tree connecting outcomes → opportunity statements (from canvas runs) → parked solutions → experiments.
