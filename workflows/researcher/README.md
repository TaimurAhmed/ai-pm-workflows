# Researcher Workflow 🚧

**Status:** TBA — parked, shape captured below.

**Where it sits:** alongside every other workflow — a support workflow, not a stage. Any box on any canvas can dispatch it.

**The idea:** when populating a canvas (or writing a brief) hits a factual unknown — *how does this company make money? what's their pricing? who owns them? what jargon do they use internally?* — don't guess and don't stall the session. Dispatch a **research sub-agent** to verify from primary sources (company website, pricing pages, annual reports / Companies House filings, credible press) while the session continues. Findings return with sources, clearly separating **verified fact** from **still-assumption**.

**Why it matters:** it operationalises the "flag, rationalise, defer" ground rule — gaps get flagged *and* filled in parallel, without breaking the time-box or the flow of the team conversation.

**What it will produce:** a short sourced fact-pack per question, appended to the run folder so Synthesise inherits verified facts instead of vibes.

_First live use: verifying Checkatrade's revenue model mid-canvas (2026-07-05)._
